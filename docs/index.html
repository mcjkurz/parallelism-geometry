Parallelism as Geometric Alignment

Finding dimensions where meaning converges

Drag to explore. Click Rotate to animate.

Two word vectors can point in different directions yet appear aligned from a certain viewpoint.

Rotating the view is like choosing a query direction. Identifying parallelism can be understood as finding a direction along which different words project similarly.

Geometrically, this means finding a query perpendicular to the dimensions where the vectors differ and thus collapsing that variation from view.
